# 🎮 Alias - Онлайн игра в слова

Мультиплеерная онлайн-версия популярной игры Alias. Объясняй слова, не называя их, и побеждай!

## ✨ Возможности

- 🌐 **Мультиплеер** - играйте с друзьями онлайн по ссылке
- 👥 **2 команды** - красные vs синие
- 📚 **Огромная база слов** - слова загружаются из открытых словарей
- ⚙️ **Настройки** - время раунда, очки для победы, штраф за пропуск
- 📱 **Адаптивный дизайн** - работает на телефонах и компьютерах

## 🚀 Быстрый старт

### Локальный запуск

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки (сервер + клиент)
npm run dev
```

Откройте http://localhost:5173

### Отдельный запуск

```bash
# Только сервер
npm run dev:server

# Только клиент
npm run dev:client
```

## 🌍 Деплой

### Backend (Render / Railway / Heroku)

1. Создайте новый Web Service
2. Укажите директорию: `server`
3. Build command: `npm install`
4. Start command: `npm start`
5. Добавьте переменную `CLIENT_URL` с URL вашего фронтенда

### Frontend (Vercel / Netlify / GitHub Pages)

1. Создайте новый проект
2. Укажите директорию: `client`
3. Build command: `npm run build`
4. Output directory: `dist`
5. Добавьте переменную `VITE_SERVER_URL` с URL вашего бэкенда

## 🎯 Как играть

1. **Создайте комнату** - введите имя и нажмите "Создать"
2. **Поделитесь ссылкой** - отправьте код или ссылку друзьям
3. **Разделитесь на команды** - минимум по 1 игроку в каждой
4. **Начните игру** - хост нажимает "Начать игру"
5. **Объясняйте слова** - не называя само слово и однокоренные
6. **Набирайте очки** - первая команда до цели побеждает!

## 🛠 Технологии

- **Frontend**: React, Vite, TailwindCSS, Socket.io-client
- **Backend**: Node.js, Express, Socket.io
- **Слова**: API словарей (Datamuse, Russian word frequency list)
